Status: Operational correction to the authorized Observatory upgrade. Independent shipped-renderer evidence confirms a visible defect in the bounded pressure geometry. This is an implementation correction, not a new product design.

## Reproduction and evidence

The actual renderer on AMD Radeon 890M at DPR 1 renders 257 radius-2, depth-4 basins on a 17-column grid with 9-unit spacing. Subject active-36 is at (18,18). At camera position (21,5,24), target (18,-1,18), FOV 40 and a 1200x900 CSS pixel viewport, global detailScale 8 produces visibly angular contour/rim steps. Actual production geometry has 73,006 vertices. Projected production-triangle versus analytic height error under the disclosed radial sampling method is 17.862985542608232 CSS pixels. Ordinary circle/ellipse close views remain smooth, with maximum 0.737432 pixels.

The independent local dense reference retains the unchanged shipped shader and all 257 field contributions, reducing the local projected diagnostic to 1.352841 pixels and visually smoothing the steps. Its cropped geometry is a diagnostic control, not a complete-landscape production implementation. The geometric diagnostic is not raster silhouette extraction and no owner-approved numeric release threshold is implied.
