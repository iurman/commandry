# Interconnected MVP campaign

**Status: Operational**

**Updated:** 2026-09-27

The user has asked for every roadmap area to reach a useful MVP depth before
the VPS and real integrations are connected. The roadmap phases now name
workstreams, not deferred releases. This ledger records local evidence and the
next useful gap without turning open product questions into canonical choices.
All fixture sources, fake agent results, and simulated actions must remain
explicitly labeled.

No local simulation satisfies a real-source, production-authentication, or VPS
recovery exit signal. A feature reaches local MVP depth when its UI, versioned
API, PostgreSQL state, worker behavior where relevant, provenance, and a
desktop/phone review path work together. Each committed slice records test
evidence and a new next step in the campaign state note.
